# Aplicación AgroConecta

Proyecto del curso CC3090 – Ingeniería de Software 1  
Universidad del Valle de Guatemala  
Semestre I – 2026  

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una aplicación móvil que permita a agricultores guatemaltecos adquirir insumos agrícolas de manera eficiente, confiable y accesible, integrando funcionalidades de comparación de precios, distribuidores verificados, asesoría técnica y entrega directa a finca.
